# ==========================================================
# WHAT IS ABSTRACTION?
# ==========================================================

# Definition:
# Abstraction is one of the four pillars of Object-Oriented Programming (OOP).
# It means hiding the internal implementation details and showing
# only the essential features to the user.

# In simple words:
# Show WHAT an object does,
# Hide HOW it does it.

# Example:
# ATM Machine
# You only know:
# ✔ Insert Card
# ✔ Enter PIN
# ✔ Withdraw Money
# ✔ Check Balance
#
# You don't know:
# ✖ How the server validates your PIN
# ✖ How money is counted
# ✖ How the database updates
#
# This is Abstraction.

# ==========================================================
# REAL-LIFE EXAMPLES OF ABSTRACTION
# ==========================================================

# 1. Car
# User knows:
# ✔ Start()
# ✔ Brake()
# ✔ Accelerate()
#
# User doesn't know:
# ✖ Engine combustion
# ✖ Fuel injection process
# ✖ Gear mechanism

# ----------------------------------------------------------

# 2. Mobile Phone
# User knows:
# ✔ Call
# ✔ Camera
# ✔ Internet
#
# Hidden:
# ✖ Signal processing
# ✖ Memory allocation
# ✖ CPU scheduling

# ----------------------------------------------------------

# 3. TV Remote
# Press Power Button
#
# Hidden:
# ✔ Infrared Signals
# ✔ Circuit Communication
# ✔ Internal Electronics

# ==========================================================
# WHY DO WE USE ABSTRACTION?
# ==========================================================

# ✔ Hide unnecessary details
# ✔ Increase security
# ✔ Reduce complexity
# ✔ Improve code readability
# ✔ Easy maintenance
# ✔ Better scalability
# ✔ Focus only on important functionalities

# ==========================================================
# HOW IS ABSTRACTION ACHIEVED IN PYTHON?
# ==========================================================

# Python provides abstraction using:

# 1. Abstract Classes
# 2. Abstract Methods
# 3. ABC Module

# ==========================================================
# ABSTRACT CLASS
# ==========================================================

# Definition:
# A class that cannot be instantiated (cannot create objects)
# and is meant to be inherited by other classes.

# Abstract classes may contain:
#
# ✔ Abstract Methods
# ✔ Normal Methods
# ✔ Constructors
# ✔ Variables

# ==========================================================
# ABC MODULE
# ==========================================================

# ABC stands for:
# Abstract Base Class

# Python provides the abc module
# to create abstract classes.

# Import Statement:

# from abc import ABC, abstractmethod

# ABC
# -> Used to create Abstract Class

# abstractmethod
# -> Used to create Abstract Method

# ==========================================================
# ABSTRACT METHOD
# ==========================================================

# Definition:
# An abstract method is a method
# that has only declaration,
# but NO implementation.

# Example:

# from abc import ABC, abstractmethod
#
# class Animal(ABC):
#
#     @abstractmethod
#     def sound(self):
#         pass

# Here,
# sound() has no body.
# Child classes must implement it.

# ==========================================================
# RULES OF ABSTRACT METHODS
# ==========================================================

# ✔ Must use @abstractmethod decorator
#
# ✔ Must be inside an Abstract Class
#
# ✔ Child class MUST override it
#
# ✔ Cannot create object of Abstract Class

# ==========================================================
# WHY CAN'T WE CREATE OBJECT OF ABSTRACT CLASS?
# ==========================================================

# Because the class is incomplete.

# Example:

# class Shape(ABC):
#
#     @abstractmethod
#     def area(self):
#         pass

# Shape has no implementation of area().

# Therefore,

# Shape()

# Gives Error.

# ==========================================================
# WHAT HAPPENS IF CHILD CLASS DOESN'T IMPLEMENT
# ABSTRACT METHOD?
# ==========================================================

# Python throws TypeError.

# Example:

# class Dog(Animal):
#     pass

# Dog()

# Error:
# Can't instantiate abstract class Dog
# with abstract method sound

# ==========================================================
# ABSTRACT CLASS CAN HAVE NORMAL METHODS
# ==========================================================

# Yes.

# Example:

# class Animal(ABC):
#
#     @abstractmethod
#     def sound(self):
#         pass
#
#     def sleep(self):
#         print("Sleeping")

# Here,

# sound()
# -> Abstract

# sleep()
# -> Normal

# ==========================================================
# ABSTRACT CLASS CAN HAVE CONSTRUCTOR
# ==========================================================

# Yes.

# Example:

# class Animal(ABC):
#
#     def __init__(self):
#         print("Constructor")
#
#     @abstractmethod
#     def sound(self):
#         pass

# Constructors are inherited by child classes.

# ==========================================================
# ABSTRACT CLASS CAN HAVE VARIABLES
# ==========================================================

# Yes.

# Example:

# class Animal(ABC):
#
#     animal_type = "Mammal"

# ==========================================================
# FLOW OF ABSTRACTION
# ==========================================================

# Abstract Class
#        ↓
# Abstract Method
#        ↓
# Child Class
#        ↓
# Method Implementation
#        ↓
# Object Creation
#        ↓
# Call Method

# ==========================================================
# EXAMPLE FLOW
# ==========================================================

# Vehicle (Abstract Class)
#
#        ↓
#
# start() (Abstract Method)
#
#        ↓
#
# Car
# Bike
# Truck
#
#        ↓
#
# Each class provides its own implementation.

# ==========================================================
# ABSTRACT CLASS VS NORMAL CLASS
# ==========================================================

# Normal Class

# ✔ Object can be created
# ✔ Methods may have implementation
# ✔ Used directly

# ----------------------------------------------------------

# Abstract Class

# ✖ Cannot create object
# ✔ Used only for inheritance
# ✔ May contain abstract methods
# ✔ Provides common blueprint

# ==========================================================
# ABSTRACT METHOD VS NORMAL METHOD
# ==========================================================

# Abstract Method

# ✔ Only declaration
# ✔ No implementation
# ✔ Child must override

# ----------------------------------------------------------

# Normal Method

# ✔ Has implementation
# ✔ Child may override
# ✔ Optional

# ==========================================================
# ABSTRACTION VS ENCAPSULATION
# ==========================================================

# Abstraction

# Hides implementation details.

# Focus:
# What object does.

# Example:
# ATM Machine

# ----------------------------------------------------------

# Encapsulation

# Hides data.

# Focus:
# Protect object data.

# Example:
# Private Variables

# ==========================================================
# ABSTRACTION VS INHERITANCE
# ==========================================================

# Abstraction

# Defines blueprint.

# ----------------------------------------------------------

# Inheritance

# Reuses code.

# ==========================================================
# ABSTRACTION VS POLYMORPHISM
# ==========================================================

# Abstraction

# Hides implementation.

# ----------------------------------------------------------

# Polymorphism

# Same interface,
# Different implementation.
