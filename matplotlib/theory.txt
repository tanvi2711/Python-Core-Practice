1. WHAT IS MATPLOTLIB?
--------------------------------------------------------------------

Matplotlib is an open-source Python library used for Data Visualization.
It helps represent data graphically so that trends, patterns, comparisons,
and relationships can be understood easily.

Matplotlib was created by John D. Hunter in 2003 and is one of the most
widely used visualization libraries in Python.

It is commonly used in:
• Data Analytics
• Data Science
• Machine Learning
• Artificial Intelligence
• Scientific Research
• Business Intelligence
• Financial Analysis
• Academic Projects

====================================================================
2. WHY DO WE USE MATPLOTLIB?
--------------------------------------------------------------------

Raw data is difficult to understand.

Example:

Sales = [1200, 1800, 2500, 3200, 4100]

Instead of reading numbers, Matplotlib converts them into graphs,
making it easier to analyze growth, decline, comparisons, and trends.

Benefits:
• Makes data easy to understand
• Finds hidden patterns
• Detects outliers
• Compares multiple datasets
• Creates professional reports
• Supports decision making

====================================================================
3. FEATURES OF MATPLOTLIB
--------------------------------------------------------------------

• Free and Open Source

4. MATPLOTLIB ARCHITECTURE
--------------------------------------------------------------------

                   Python Program
                         |
                         V
                matplotlib.pyplot
                         |
          --------------------------------
          |              |               |
       Figure          Axes           Graph
          |              |
          |         X-axis & Y-axis
          |
      Complete Canvas

Explanation:

Figure  -> Entire window or canvas.
Axes    -> Area where graph is drawn.
Axis    -> X-axis and Y-axis.
Plot    -> Actual visualization.

====================================================================
5. IMPORTING MATPLOTLIB
--------------------------------------------------------------------

import matplotlib.pyplot as plt

Explanation:

matplotlib        -> Main library
pyplot            -> Plotting module
plt               -> Alias (shortcut)

====================================================================
12. HISTOGRAM
--------------------------------------------------------------------

Purpose:
Shows frequency distribution of numerical data.

Unlike a Bar Chart, histogram bars touch each other because the data is
continuous.

Used For:
• Age Distribution
• Salary Distribution
• Height Analysis

====================================================================
13. PIE CHART
--------------------------------------------------------------------

Purpose:
Shows percentage contribution of each category.

Example:

Company Expenses

Rent          40%
Salary        30%
Electricity   20%
Others        10%

Used For:
• Budget Analysis
• Market Share
• Survey Results

====================================================================
14. BOX PLOT
--------------------------------------------------------------------

Purpose:
Displays the spread of data and identifies outliers.

Shows:
• Minimum
• Maximum
• Median
• Quartile 1 (Q1)
• Quartile 3 (Q3)
• Outliers

Mostly used in Data Science and Statistics.
