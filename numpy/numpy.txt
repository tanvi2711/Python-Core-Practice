# What is NumPy?
# ----------------
# NumPy (Numerical Python) is a powerful Python library used for:
# • Numerical Computing
# • Mathematical Operations
# • Scientific Computing
# • Data Analysis
# • Machine Learning
# • Artificial Intelligence
# • Deep Learning
#
# It provides a special data structure called ndarray (N-Dimensional Array)
# which is much faster and more efficient than Python Lists.
#
#
# -----------------------------------------------------------------------------------------------------
# Why was NumPy Created?
# -----------------------------------------------------------------------------------------------------
#
# Before NumPy:
# - Python only had Lists.
# - Lists are flexible but slow for numerical calculations.
# - Mathematical operations required loops.
# - Large datasets consumed more memory.
# - Scientific calculations became inefficient.
#
# NumPy solved these problems by introducing fast arrays implemented in C.
#
#
# -----------------------------------------------------------------------------------------------------
# Problems with Python Lists
# -----------------------------------------------------------------------------------------------------
#
# Example:
#
# list1 = [1,2,3]
# list2 = [4,5,6]
#
# print(list1 + list2)
#
# Output:
# [1,2,3,4,5,6]
#
# Instead of addition, it concatenates the lists.
#
#
# If we want:
#
# [5,7,9]
#
# We must write loops manually.
#
#
# Example:
#
# result = []
# for i in range(len(list1)):
#     result.append(list1[i] + list2[i])
#
#
# This is:
#
# ❌ More code
# ❌ Slower
# ❌ Uses more memory
#
#
# NumPy solves this in one line:
#
# arr1 + arr2
#
#

# Benefits of NumPy
# -----------------------------------------------------------------------------------------------------
#
# 1. Very Fast
#
# Arrays are written in C language internally.
#
# Therefore they execute much faster than Python Lists.
#
#
# 2. Memory Efficient
#
# Lists store references to objects.
#
# NumPy stores data in contiguous memory.
#
# Hence it consumes less memory.
#
#
# 3. Easy Mathematical Operations
#
# We can directly perform:
#
# +  -  *  /  **
#
# on entire arrays.
#
#
# 4. Supports Multi-dimensional Arrays
#
# 1D Array
#
# [1 2 3]
#
#
# 2D Array
#
# [[1 2]
#  [3 4]]
#
#
# 3D Array
#
# [[[1 2]
#   [3 4]]]

# Interview Questions
# -----------------------------------------------------------------------------------------------------
#
# Q1. What is NumPy?
#
# Ans:
# NumPy is a Python library used for numerical and scientific computing.
# It provides high-performance N-dimensional arrays and mathematical functions.
#
#
# Q2. What is ndarray?
#
# Ans:
# ndarray is the main data structure of NumPy.
# It stores homogeneous (same data type) elements efficiently.
#
#
# Q3. Why is NumPy faster than Python Lists?
#
# Ans:
# Because:
# • Written in C
# • Uses contiguous memory
# • Supports vectorization
#
#
# Q4. What is Vectorization?
#
# Ans:
# Performing operations on the entire array without using loops.
#
#
# Q5. Why do we import NumPy as np?
#
# Ans:
# To write shorter, cleaner code. It is the standard convention.
#
#
# Q6. Can NumPy store multiple data types?
#
# Ans:
# A NumPy array is designed to store elements of the same data type.
# If mixed types are provided, NumPy converts them to a common compatible type.
